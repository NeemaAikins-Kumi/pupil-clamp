**Time:** ~1:00–2:45 PM CT

## What I did
- Started my MIT THINK application (deadline: Jan 1, 11:59 PM ET — confirm on think.mit.edu)
- Brainstormed ideas: squeeze-toy grip test, smell test, rhythm/gait cueing, smart pill cap
- Chose **Pupil Clamp**: a 3D-printed headset that measures mental effort by using
  PID-controlled light to hold the pupil at a fixed size. The extra light needed = effort score.
- Why it matters: people with early memory decline (MCI) show bigger pupil dilation
  (more effort) for the same task, before test scores drop. Lab pupil machines cost thousands.
- Research question: Does the effort score rise with task difficulty, and does it differ
  between men and women?
- Set up this GitHub repo (README, LICENSE, cad/code/notes/photos folders)

## Decisions
- Start with ONE eye (pupils move together, so it's simpler)
- Build order: v0 test box → v1 printed viewer → v2 wearable with strap
- Design in Tinkercad → export STL → print in black filament (blocks light)
- Test only on healthy volunteers; never upload personal data or eye videos
